\# AGENTS.md



\## 适用范围

本文件仅适用于 `outputs/` 目录及其子目录。



\## 当前任务定位

这里的任务主要是：

\- 读取实验输出

\- 汇总表格和统计

\- 解读图表与报告

\- 追踪不同 run 的差异

\- 判断结果是否足以支撑论文 claim



\---



\## 输出目录规则

1\. `outputs/` 视为生成结果目录

2\. 优先新增结果，不覆盖历史结果

3\. 分析时必须说明基于哪个 run / 哪个文件

4\. 不要手工修改日志文件内容

5\. 若多个输出版本冲突，必须显式指出



\---



\## 分析结果时必须区分

\### 观察事实

例如：

\- 某次 run 的 Jaccard 为多少

\- 某 treatment 的 macro-F1 为多少

\- 某模型平均权重是多少



\### 推断解释

例如：

\- 权重机制呈现稀疏激活

\- 圆桌更偏向保留 V / A 类问题

\- 某模型更容易产生高价值异议



解释必须基于已观察事实，不能跳步。



\---



\## 与论文联动时

如果输出目录中的事实与论文不一致，优先信任真实输出，但不要直接改论文结论。

先明确指出：

\- 哪个文件中的结果是什么

\- 与论文哪一段不一致

\- 建议修改论文还是重新核查脚本



\---



\## 占位符处理规则

若输出还不足以支持论文中这些内容：

\- 数量

\- 比例

\- 显著性

\- 效应量

\- 接受率

\- 收敛统计



则必须明确写：

“当前 outputs 尚不足以支持该论文表述，需要补跑或补提取。”



\---



\## 输出时必须附带

1\. 基于哪个 outputs 文件 / run

2\. 观察到的事实

3\. 可以做出的解释

4\. 不能做出的结论

5\. 对论文哪些部分有直接影响
