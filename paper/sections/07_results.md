进一步比较初始问题集合（issues_r0）与最终问题集合（final_problems）的类型构成，可以观察到明显的结构性变化。在初始 issues_r0 中，四类问题的占比分别为：A 类 32.82%、V 类 30.09%、U 类 25.43%、C 类 11.66%；而在最终 final_problems 中，这一分布变为：V 类 45.89%、A 类 38.46%、U 类 14.59%、C 类仅 1.06%。这一结果表明，框架在多轮过滤与共识后更倾向于保留“Verifiable”和“Unambiguous”问题，而对“Correctness”问题则显著压缩。一个合理的解释是，正确性判断往往需要更强的领域背景与事实基准，因此在缺乏外部领域真值支持的条件下，系统更谨慎地将其保留为最终问题。

## 6.2 Result for RQ2：论证质量向量能否区分好离群与坏离群

为回答该问题，我们分析了离群事件集合H被映射到六维论证质量向量Q分数分布以及离散化判定结果。如表Ⅱ所示，在当前xxxxxx个离群事件中，系统最终将xxxxxx个判定为好离群，xxxxxx个判定为坏离群，另有xxxxxx个被保留为uncertain。从数量上看，好离群与坏离群都明显少于普通非离群评分，说明本文方法对高价值异议的定义较为严格，即本文提出的论证质量判别机制没有简单地把“偏差大小”视为唯一信号，而是能够对偏离行为进行更细粒度的质量区分，进一步根据证据充分性（Eevidence）、改写可执行性（Rrewrite_exec）、维度匹配度（Ttaxonomy_fit）等深度特征，将离群分解为不同审查价值的异议样本。

在应用本文设定的Hard Fail机制时，我们发现有 xxxxxx% 的离群事件由于在“证据充分性(E)”或“改写可执行性(R)”上的得分为 0 而被直接判定为Bad Outlier。例如，在 RLCS 数据集的条目 R4 (U维度) 中，模型 GLM-5 虽然产生了偏离基准的离群评分，但其证据项（Eevidence）得分为 0，导致触发 Hard Fail 且归一化质量分仅为 Q=0.25，被系统准确拦截。

在剔除 Hard Fail 后，基于阈值 τgood=0.60 与 τbad=0.30 的判别机制实现了对剩余离群事件的有效区隔。Mann−Whitney U检验结果显示，“好离群”在证据具体性（Sspecificity）与维度匹配度（Ttaxonomy_fit）上的子项得分显著高于“坏离群”与“不确定”事件 (p<0.001,Cliff'sd= xxxxxx)。典型的好离群样本如 RLCS 数据集中 Qwen-plus 对 R192 (V维度) 的判别：其成功指出了无观测标准的隐蔽缺陷，并提供了高操作性的改写建议，获得了 Q=0.91 的高分，未触发 Hard Fail。

因此我们得出，论证质量向量能够有效穿透数值偏差，通过“Hard Fail”过滤缺乏证据的幻觉偏差从而剔除“坏离群”，并以高统计显著性 (p<0.001) 将具备充分重构建议的少数派意见识别为“好离群”。

## 6.3 Result for RQ3：基于离群画像的模型定权结果

在本节，我们对比了由好离群强度（Gr）与坏离群强度（Br）导出的动态定权策略与传统的等权基线（Equal-Weight）在单轮次下的指标差异。采用配对 Wilcoxon 符号秩检验比较最终被接受的缺陷清单。相较于等权基线，基于画像的全局定权策略使得真正具有可执行性的“高价值缺陷”的存活率（Retention Rate）显著提升 (Z=xxxxx,p<0.05)。同时，由低权模型引入的误报率（False Positives）下降了xxxxxx。

当前实验表明，动态定权机制并不会在所有文档上强行制造权重差异，而是呈现出明显的“稀疏激活”特征。当文档中没有足够多的高质量离群或坏离群时，系统会维持近似均匀的模型权重。这意味着定权机制不会在缺乏证据的情况下任意拉开模型差距。相反，当文档中存在可区分离群质量的文档时，权重会快速分化。这表明了权重变化与离群质量判别保持一致方向，而不是简单反映模型是否“接近中位数”。

如表Ⅲ，从跨文档平均值来看，在实际成功参与的文档上，DeepSeek-Reasoner的平均权重最高（0.4009），其次为Qwen-plus（0.3498）和GPT-5.1（0.3367），Kimi为0.2669，GLM-5最低（0.1886）。不过，这一结果应该谨慎解读，因为不同模型的参与文档数并不相同，且部分模型受 API 稳定性影响。更有解释力的观察在于：一旦文档中出现可区分的好/坏离群，权重机制能够显式奖励高价值异议并惩罚低质量偏离。这一现象从当前批次角度支持了 RQ3。

## 6.4 Result for RQ4：圆桌共识的收敛性与最终输出行为

为了量化条目级圆桌讨论的有效性，我们测量了多轮迭代中候选缺陷集合的收敛性为与分数波动，如表Ⅳ所示。基于我们得到的实验报告，圆桌机制在不同文档上表现出不同的收敛形态，但总体上能够把候选问题集合压缩为结构化且可操作的最终问题清单。其中，当候选集合较大且分歧较弱时，系统更快表现出集合收敛，而当候选集合较小但问题影响力逐轮上升时，系统则更表现为分数收敛而非立即集合收敛。这说明“固定权重 + 动态置信度”的圆桌并不是单一模式地工作，而是会随着问题空间密度与模型分歧强度的不同，表现出不同的收敛路径。

从圆桌过程来看，当前20个需求文档中有xxxxxx个在问题集合层面达到收敛，issue_converged比例为xxxxxx%；最终一轮的平均问题集合Jaccard相似度为0.8656。这表明尽管多模型在评分层面仍然存在波动，但在“哪些问题值得保留”这一集合层面，系统通常能够在 2~3 轮之内收敛到较稳定的结果。

与此相对，score_converged 在当前批次中为0，最终一轮的平均 max_score_diff 仍为 1.3159。这说明本文框架更适合作为“问题发现与筛选”机制，而不是追求 Likert 分数本身的完全稳定。换言之，圆桌讨论优先稳定的是团队问题集合，而不是连续分数值；这与本文最终输出是“问题清单”而非“平均评分”的目标是一致的。

从问题压缩效果看，圆桌机制具有明显的过滤与聚焦作用。若以 issues_r0 为初始问题池，20 个需求文档的原始问题总数为xxxxxx条，而最终 final_problems 为 xxxxxx 条，整体保留率仅为 12.2%；按文档计算，中位保留率为 17.0%。例如，2001 - beyond 从 435 条初始问题压缩到 26 条最终问题，2009 - inventory 2.0 从 990 条压缩到 75 条，2005 - pontis 从 1381 条压缩到 235 条。可见，圆桌并不是简单地重复初始评分，而是在较大规模的原始问题池中执行了显著的优先级压缩与筛选。

从最终问题类型看，V 类与 A 类问题在保留后的比重明显上升，分别占 45.89% 和 38.46%。这表明圆桌在多模型讨论后更容易形成共识的问题，主要集中在“需求是否可验证”和“需求是否存在歧义”这两类直接影响需求可执行性的维度上。因而，从收敛性和输出形态两个角度看，当前结果支持 RQ4：融合固定权重与动态置信度的条目级圆桌机制，能够在有限轮次内产生更紧凑、更可操作的团队问题集合。
